# 주간 업무 보고서 작성 시나리오

> 실습 2-2에서 사용하는 가상 업무 상황이다.

## 현재 업무

교육운영팀은 팀장 윤재희와 팀원 네 명(김도현, 이수아, 박준영, 최유진)으로 구성된다. 팀원은 공유 스프레드시트의 `업무기록` 시트에 그날 한 업무를 한 줄씩 적는다.

팀장은 매주 금요일 오후 두 시간 정도를 들여 한 주의 기록을 읽고 주간 업무 보고서를 작성한 뒤, 17시까지 부서장에게 메일로 보낸다. 부서장은 금요일 17시 30분 부서 회의에서 각 팀의 보고서를 사용한다.

## 업무기록 시트의 작성 규칙

| 열 | 뜻 | 작성 규칙 |
|---|---|---|
| `entry_id` | 기록 번호 | 시트가 자동으로 붙인다 |
| `work_date` | 업무를 한 날짜 | `YYYY-MM-DD` |
| `author` | 작성한 팀원 | 팀원 이름 |
| `category` | 업무 구분 | `교육과정`, `운영`, `홍보` 중 하나 |
| `content` | 업무 내용 | 한 문장 |
| `hours` | 소요 시간 | 시간 단위 숫자, 0.5 단위(예: `1.5`) |
| `status` | 진행 상태 | `done`(완료), `in_progress`(진행 중), `blocked`(보류·지원 필요) 중 하나 |

규칙은 팀 안내 문서에 적혀 있지만 시트에서 입력값을 강제하지는 않는다.

## 보고서 형식

1. 이번 주 주요 완료 업무(`done`)
2. 진행 중인 업무와 다음 주 계획(`in_progress`)
3. 이슈와 지원 요청(`blocked`)
4. 팀원별 소요 시간 합계

## 검토 중인 자동화안

1. 금요일 14시에 이번 주 월요일부터 금요일까지의 기록을 가져온다.
2. 팀원별 제출 여부와 각 행의 작성 규칙을 검사한다.
3. 소요 시간 합계는 규칙으로 계산한다.
4. LLM이 보고서 1~3절의 초안을 쓴다.
5. 팀장이 초안을 확인하고 고치거나 승인한다.
6. 승인된 보고서를 부서장에게 메일로 보낸다.

## 업무 조건

| 항목 | 내용 |
|---|---|
| 이번 주 기간 | 2026-09-14(월) ~ 2026-09-18(금) |
| 발송 기한 | 금요일 17시. 이후에 보내면 부서 회의 자료에 들어가지 못한다 |
| 발송 권한 | 부서장에게 가는 메일은 팀장이 확인한 뒤에만 보낸다 |
| 팀장의 걱정 | LLM이 기록에 없는 성과를 그럴듯하게 써 넣는 것 |
| 팀원 사정 | 금요일 오후에는 외부 일정으로 기록을 늦게 올리는 팀원이 있다 |
