## 1. 이 집행은 승인이 필요한가

먼저 승인을 둘지 판단한다. 승인은 공짜가 아니라 처리가 멈추는 비용을 치르고 얻는 것이다.

| 질문 | 답 | 판단 근거 |
|---|---|---|
| 이 집행은 무엇을 바꾸는가 | | |
| 잘못 집행되면 되돌릴 수 있는가. 되돌리는 데 무엇이 필요한가 | | |
| 판단의 입력을 믿을 수 있는가(사람이 쓴 문장인가, 시스템의 값인가) | | |
| 규정이 사람의 확인을 요구하는가 | | |
| **판단: 승인을 두는가** | | |

승인을 두지 않기로 했다면 아래는 채우지 않는다. 대신 규칙 검사만으로 무엇을 막는지 적는다.
