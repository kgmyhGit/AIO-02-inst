# 법인카드 사용 내역 정리 기준

> 3장 실습 3-4에서 사용하는 가상의 사내 기준이다. 실제 회계 규정이 아니다.

## 상황

교육운영팀은 팀 법인카드 한 장을 함께 쓴다. 카드사 내역을 내려받으면 사용처와 금액만 있고 지출 항목이 없어서, 팀 총무가 월말마다 한 줄씩 보며 지출 항목을 붙이고 합계를 낸다. 표기 방식이 제각각이라 합계가 한 번에 맞는 일이 드물다.

## 정리한 결과가 갖춰야 할 형식

| 필드 | 데이터 타입 | 형식·허용 값 | 설명 |
|---|---|---|---|
| `row_id` | 문자열 | 원본 그대로 | 카드 사용 내역 한 건을 구분하는 번호다. 예: `E-01` |
| `used_at` | 문자열 | ISO 8601, `+09:00` 포함 | 카드를 사용한 날짜와 시각이다. 시각을 모르면 그날 `00:00:00+09:00`으로 본다 |
| `merchant` | 문자열 또는 `null` | 빈 문자열을 쓰지 않는다 | 카드를 사용한 가게나 업체의 이름이다. 예: `한빛분식`. 사용처가 비어 있으면 `null` |
| `amount` | 정수 | 원 단위 | 결제한 금액이다. 쉼표와 '원'을 뗀 값이며, 값이 없으면 `null` |
| `account` | 문자열 | `meal`, `transport`, `office_supplies`, `book`, `other` | 지출이 어떤 성격의 비용인지 나타내는 **지출 항목**이다. 아래 분류 규칙으로 정한다 |
| `receipt_required` | 불리언 | — | 영수증 원본을 첨부해야 하는 건인지 나타낸다. 아래 확인 기준으로 정한다 |
| `needs_check` | 불리언 | — | 총무가 직접 확인해야 하는 건인지 나타낸다. 아래 확인 기준에 해당하면 `true` |

## 지출 항목 분류 규칙

사용처 또는 메모에 아래 낱말이 있으면 해당 지출 항목으로 본다. 위에서부터 차례로 검사하고 처음 맞는 것을 쓴다.

| 지출 항목 | 값 | 찾을 낱말 |
|---|---|---|
| **식대** | `meal` | 식당, 분식, 중식, 한식, 카페, 커피, 식사, 점심, 식대 |
| **교통비** | `transport` | 택시, 주유, 고속, 터미널, 철도, 버스, 출장 |
| **사무용품비** | `office_supplies` | 문구, 오피스, 사무, 용지, 마커 |
| **도서구입비** | `book` | 서점, 도서, 교재 |
| **기타** | `other` | 위에 해당하지 않는 경우 |

한 항목이 여러 낱말에 걸리면 표의 위쪽 지출 항목을 쓴다. 이 순서는 팀에서 정한 것이며, 실제로는 지출 항목을 잘못 붙이는 경우가 생기므로 총무가 최종 확인한다.

## 확인 기준

- 한 건의 금액이 **50,000원을 넘으면** 영수증 원본을 첨부해야 한다. `receipt_required`를 `true`로 둔다.
- 다음 중 하나라도 해당하면 `needs_check`를 `true`로 두고 총무가 직접 본다.
    - 금액을 알 수 없다(`amount`가 `null`).
    - 사용처를 알 수 없다(`merchant`가 `null`).
    - 지출 항목이 `other`로 정해졌다.
