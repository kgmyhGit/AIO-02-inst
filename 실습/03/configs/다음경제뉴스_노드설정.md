# Daum 경제 뉴스 수집 노드 설정

> 3장 실습 3-5(Daum 경제 뉴스 수집과 저장)에서 쓴다. 선택자는 2026년 11월의 Daum 뉴스 페이지로 확인했다. 사이트의 구조가 바뀌면 선택자를 다시 찾아야 한다.

## 0. 저장할 테이블

`n8n_exam` 데이터베이스에 아래 테이블을 한 번 만든다. `Postgres` 노드의 Execute Query로 실행한다.

```sql
CREATE TABLE daumnews (
    num        integer GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    title      varchar(200),
    content    varchar(4000),
    created_at timestamptz DEFAULT now()
);
```

| 열 | 뜻 | 누가 채우는가 |
|---|---|---|
| `num` | 저장 순서대로 매기는 번호 | 데이터베이스 |
| `title` | 기사 제목 | 워크플로우 |
| `content` | 기사 본문. 4,000자까지 | 워크플로우 |
| `created_at` | 저장한 시각(시간대 포함) | 데이터베이스 |

시험한 행을 모두 지우고 번호를 1부터 다시 매기려면 다음을 실행한다.

```sql
TRUNCATE TABLE daumnews RESTART IDENTITY;
```

| 자격 증명 이름 | 유형 | 넣을 값 |
|---|---|---|

## 2. 노드와 설정

| 노드 이름 | 노드 | 설정 |
|---|---|---|
| `직접 실행` | Manual Trigger | 없음 |
| `매시간` | Schedule Trigger | Trigger Interval Hours, 1시간마다 |
| `경제 뉴스 목록 페이지` | HTTP Request | GET `https://news.daum.net/economy`. Send Headers를 켜고 Using JSON으로 `{"user-agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/151.0.0.0 Safari/537.36"}` |
| `목록에서 주소와 제목 추출` | HTML | Extract HTML Content, JSON Property `data`. 뽑을 값 두 개는 아래 표 |
| `기사로 나누기` | Code | 3절의 코드 |
| `한 건씩 반복` | Loop Over Items | Batch Size 1 |
| `기사 페이지` | HTTP Request | GET `{{ $json.href }}`, 헤더는 목록 페이지와 같다 |
| `본문 추출` | HTML | Extract HTML Content, Key `content`, CSS Selector `#mArticle div.article_view > section`, Skip Selectors `figure`, Options › Trim Values 켬 |
| `기사 저장` | Postgres | 자격 증명 `예제 DB`, Insert, Schema `public`, Table `daumnews`, Map Each Column Manually. `title`은 `{{ $('한 건씩 반복').item.json.title }}`, `content`는 `{{ ($json.content ?? '').slice(0, 4000) }}` |
| `잠시 기다리기` | Wait | Resume After Time Interval, Wait Amount `{{ Math.floor(Math.random() * 2) + 1 }}`, Wait Unit Seconds |
| `저장 결과 묶기` | Aggregate | All Item Data, Put Output in Field `data` |
| `Discord 알림` | Discord | Connection Type Webhook, 자격 증명 `Discord 실습 채널`, Content는 아래 |

`목록에서 주소와 제목 추출`의 뽑을 값:

| Key | CSS Selector | Return Value | Return Array |
|---|---|---|---|
| `link_href` | `ul.list_newsheadline2 > li > a` | Attribute, Attribute `href` | 켬 |
| `link_title` | `ul.list_newsheadline2 > li > a strong.tit_txt` | Text | 켬 |

`Discord 알림`의 Content:

```text
{{ $json.data.length }}개 뉴스를 저장했습니다. ({{ $now.toFormat('yyyy-MM-dd HH:mm') }})
```

연결:

- `직접 실행`과 `매시간` → `경제 뉴스 목록 페이지` → `목록에서 주소와 제목 추출` → `기사로 나누기` → `한 건씩 반복`
- `한 건씩 반복`의 loop 출력 → `기사 페이지` → `본문 추출` → `기사 저장` → `잠시 기다리기` → `한 건씩 반복`의 입력
- `한 건씩 반복`의 done 출력 → `저장 결과 묶기` → `Discord 알림`

## 3. 기사로 나누기 코드

Mode는 기본값 Run Once for All Items로 둔다. 그대로 붙여 넣어 실행할 수 있다.

```javascript
// 목록에서 뽑은 두 배열(주소, 제목)을 같은 순서끼리 짝지어 기사 한 건씩의 아이템으로 만든다.
const hrefs = $json.link_href ?? [];
const titles = $json.link_title ?? [];

// 두 배열의 길이가 다르면 짝이 어긋난다. 조용히 넘어가지 않고 멈춘다.
if (hrefs.length !== titles.length) {
  throw new Error(`주소 ${hrefs.length}개와 제목 ${titles.length}개의 수가 다릅니다. 목록 선택자를 확인하세요.`);
}

return hrefs.map((href, i) => ({
  json: { href, title: titles[i] },
}));
```

## 4. 저장된 행 확인

```sql
SELECT num, title, length(content) AS content_length, created_at
FROM daumnews
ORDER BY num DESC
LIMIT 10;
```
