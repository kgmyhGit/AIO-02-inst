# 역할 계약서 양식

> 역할 하나마다 이 양식을 한 벌 채운다. 7장 이론 7.4절의 역할 계약 항목을 따른다.
> 파일 이름은 `07_역할계약_대상.md`처럼 짓는다. 한 파일에 역할 여러 개를 이어 써도 된다.

## 사용 방법

- **만들기 전에 쓴다.** 계약을 먼저 써야 역할 사이에 넘길 값과 검사할 규칙이 정해진다.
- 출력 필드는 **모델이 채우는 것과 워크플로우가 채우는 것을 나누어** 적는다. 식별자와 확인된 사실은 워크플로우가 채운다.
- "할 수 없는 일"과 "끝내는 조건"을 비워 두지 않는다. 도구 계약(4장)에 없던 두 항목이며, 모델이 넘지 말아야 할 선과 멈출 때를 정한다.

## 역할: (이름)

| 항목 | 내용 |
|---|---|
| **하는 일** | 한두 문장 |
| **입력** | 필드 이름(데이터 타입). 누가 채워 넘기는가 |
| **출력**(**모델이 채운다**) | 필드 이름(데이터 타입, 허용 값) |
| **출력**(**워크플로우가 채운다**) | 필드 이름(데이터 타입). 어디에서 가져오는가 |
| **쓸 수 있는 도구** | 도구 이름. 도구마다 모델이 채우는 입력과 워크플로우가 정하는 입력 |
| **할 수 없는 일** | |
| **끝내는 조건** | 반복 한도, 조기 종료 조건, 끝낼 때 내는 `status` |
| **실패했을 때** | 오류, 형식 위반, 한도 초과가 나면 무엇을 기록하는가 |
