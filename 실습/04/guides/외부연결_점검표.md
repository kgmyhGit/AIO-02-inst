# 외부 연결 점검표

> 4장에서 새로 생기는 연결(모의 API, OpenAI, 공개 API)에서 막혔을 때 증상별로 확인할 곳을 정리했다.
> 컨테이너가 실행되지 않는 문제는 3장의 [`환경점검표.md`](../../../03/템플릿_가이드/guides/환경점검표.md)를 먼저 본다.

## 모의 주문 API

| 증상 | 확인할 위치 | 해결 |
|---|---|---|
| `docker compose ps`에 `mock-api`가 없다 | 쓰고 있는 `compose.yml` | 4장 구성 파일로 바꾸었는지 확인하고 `docker compose up -d`를 다시 실행한다 |
| `mock-api`가 곧바로 멈춘다 | `docker compose logs mock-api` | "MOCK_API_KEY 환경 변수가 비어 있습니다"가 보이면 `.env`에 키를 더한다. "No such file"이 보이면 `compose.yml`과 같은 폴더에 `mock-api` 폴더가 있는지 확인한다 |
| n8n에서 호출하면 `ECONNREFUSED` | `HTTP Request` 노드의 URL | `localhost`를 `mock-api`로 바꾼다. 컨테이너 안에서 `localhost`는 n8n 자신이다 |
| 내 컴퓨터의 터미널에서 호출하면 연결이 안 된다 | 주소와 포트 | 터미널에서는 `http://localhost:8000`이다. 8000 포트를 다른 프로그램이 쓰고 있으면 `compose.yml`의 `ports` 왼쪽 숫자를 바꾼다 |
| 항상 401이 온다 | 자격 증명의 Name과 Value | Name이 `X-API-Key`와 글자까지 같은지, Value에 `.env`의 `MOCK_API_KEY` 값을 앞뒤 공백 없이 넣었는지 확인한다. `.env`를 고쳤다면 `docker compose up -d`로 컨테이너를 다시 만든다 |
| 교환 조회가 항상 `option_not_offered`다 | 보낸 `option` 값 | 재고 목록의 표기와 글자까지 같아야 한다. `L`이 아니라 `그레이 L`처럼 적는다 |
| 한글 옵션을 터미널에서 보내면 깨진다 | 명령 | `curl -G --data-urlencode "option=값"` 형식을 쓴다. PowerShell에서는 3장 `웹문의_보내기_안내.md`처럼 `curl.exe`를 쓴다 |

모의 API가 명세대로 응답하는지는 강사가 `mock-api/check_api.py`로 점검할 수 있다.

## OpenAI 채팅 모델

| 증상 | 확인할 위치 | 해결 |
|---|---|---|
| 자격 증명 저장 시 연결 확인이 실패한다 | API 키 | 키를 다시 복사한다. 앞뒤 공백이 들어가지 않게 한다 |
| 모델 목록에 `gpt-6-luna`가 없다 | `OpenAI Chat Model`의 Model 칸 | 목록에서 찾지 못하면 ID로 직접 입력하는 방식을 쓴다. 조직의 계정에서 그 모델을 쓸 수 있는지 강사에게 확인한다 |
| 429 오류가 난다 | OpenAI 계정의 사용 한도와 결제 상태 | 한도를 넘었거나 결제 수단이 없는 경우다. 강사에게 알린다. 같은 실행을 짧은 간격으로 반복하지 않는다 |
| 응답이 오래 걸리거나 시간 초과가 난다 | 외부망 연결 | 아래 "외부망" 항목을 본다 |
| 설정한 옵션이 무시되거나 오류가 난다 | `OpenAI Chat Model`의 Options | 모델에 따라 지원하지 않는 옵션이 있다. 교재가 안내하지 않은 옵션은 비워 둔다 |

**API 키는 자격 증명에만 넣는다.** 워크플로우의 노드 칸, 시스템 메시지, `.env` 파일에 적지 않는다.

## 공개 API(Open-Meteo, Frankfurter)

| 증상 | 확인할 위치 | 해결 |
|---|---|---|
| 호출이 시간 초과로 끝난다 | 외부망 | 교육장 네트워크에서 외부 접속이 막혀 있을 수 있다. 모의 API의 대체 경로(`http://mock-api:8000/practice/...`)로 기본 주소만 바꾼다 |
| 400 오류와 `reason`이 온다 | 쿼리 파라미터 이름 | `reason`에 적힌 이름을 명세와 대조한다 |
| 지명 검색 결과에서 값을 못 읽는다 | 출력 패널 | 결과가 없으면 `results` 필드 자체가 없다. [`오류응답_예제.md`](오류응답_예제.md)를 본다 |

## 외부망

| 확인할 것 | 방법 |
|---|---|
| **n8n 컨테이너에서 밖으로 나갈 수 있는가** | 새 워크플로우에 `HTTP Request` 노드 하나를 두고 `https://api.open-meteo.com/v1/forecast?latitude=37.57&longitude=126.98&daily=temperature_2m_max&forecast_days=1`을 GET으로 실행한다. 응답이 오면 연결된 것이다 |
| **회사 프록시가 있는가** | 결과가 오지 않으면 강사에게 네트워크 조건을 확인한다. 이 교재는 프록시 설정을 다루지 않는다 |
