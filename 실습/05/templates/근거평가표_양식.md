# 근거 평가표 양식

> 벡터 검색으로 근거를 찾아 답하는 흐름을 질문마다 평가하는 양식이다. 5장 실습 5-6, 5-7에서 쓴다.
> 파일 이름은 `05_근거평가표_반품배송.md`처럼 `장번호_근거평가표_대상.md`로 한다.
> 4장 계약 테스트 양식을 벡터 검색에 맞게 넓힌 것이다. 이론 5.6절을 참고한다.

## 1. 실행 조건

같은 질문 세트라도 아래 값이 다르면 결과를 비교할 수 없다. 평가할 때마다 적는다.

| 항목 | 값 |

## 2. 판정 기준

| 판정 | 질문 | 판정하는 쪽 | 값 |
|---|---|---|---|
| **검색 적중** | 찾아야 할 문서가 이번 턴의 벡터 검색 결과(점수 기준 안)에 있었는가? | 규칙(`판정`의 `retrieval_hit`) | 예 / 아니오 / 해당 없음 |
| **인용 정확** | 인용한 문서가 벡터 검색 결과 안에 있고, 찾아야 할 문서인가? | 규칙(`citation_ok`) | 예 / 아니오 / 해당 없음 |
| **답변 근거** | 안내문의 내용이 인용한 문서에 실제로 있는가? 문서에 없는 숫자나 절차가 섞이지 않았는가? | **사람** | 예 / 아니오 / 해당 없음 |
| **전환 적절** | 기대한 `status`로 끝났는가? 넘겨야 할 때 넘기고, 되물어야 할 때 되물었는가? | 규칙(`status_ok`) | 예 / 아니오 |

"해당 없음"은 찾아야 할 문서가 없는 질문(답이 없는 질문)이거나, 인용이 없는 결과일 때 쓴다.

## 3. 평가 결과

한 줄에 한 턴을 적는다. 여러 회차를 실행했다면 회차마다 줄을 나눈다.

| 번호 | 대화와 순서 | 질문 | 기대 `status`와 문서 | 검색어 | 벡터 검색된 문서(점수) | 인용 | 답변 요지 | 검색 적중 | 인용 정확 | 답변 근거 | 전환 적절 | 실패 유형과 고칠 곳 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | | | | |

## 4. 실패 유형과 고칠 곳

| 실패 유형 | 보이는 모습 | 먼저 볼 곳 |
|---|---|---|
| **검색 실패** | 찾아야 할 문서가 벡터 검색 결과에 없다 | 검색어(모델이 만든 `query`), 분할 설정, Limit, 점수 기준 |
| **인용 오류** | 벡터 검색하지 않은 문서나 엉뚱한 문서를 인용했다 | 시스템 메시지의 evidence 규칙, 검증 규칙 |
| **근거 밖 답변** | 인용은 맞지만 안내문에 문서에 없는 내용이 있다 | 시스템 메시지의 answer 규칙, 청크의 내용 |
| **잘못된 전환** | 답할 수 있는데 넘겼다(과잉 전환) / 넘겨야 하는데 답했다(누락 전환) | 점수 기준, 시스템 메시지의 status 규칙 |
| **기억 섞임** | 다른 세션의 내용이 답에 나왔다 | 세션 ID를 만드는 곳, 에이전트를 한 턴씩 실행하는지 |
