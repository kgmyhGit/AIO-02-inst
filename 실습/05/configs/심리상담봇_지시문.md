# 심리 상담 봇 지시문과 노션 구조

> 5장 실습 5-1에서 쓰는 시스템 메시지, 노션 데이터베이스 구조, 시험 대화다. 이 봇은 메모리와 노션 연동을 익히기 위한 실습용이며 실제 상담 서비스가 아니다.
> 시험 대화는 실습을 위해 만든 가상의 문장이다. 노션은 외부 서비스이므로 자신이나 다른 사람의 실제 고민을 입력하지 않는다.

## 1. 시스템 메시지

`AI Agent`의 **Options → System Message**에 넣는다.

```text
너는 메모리 실습을 위해 만든 심리 상담 챗봇이다.
상담자의 심리 상태를 살피고, 공감하는 말로 먼저 답한 뒤 도움이 될 만한 생각이나 작은 행동을 제안한다.
상담자가 앞에서 한 말이 있으면 앞의 대화를 보고 이어서 답한다. 앞의 대화에 없는 내용은 들은 것처럼 말하지 않는다.
의학적 진단을 내리거나 약을 권하지 않는다.
친근하고 친절한 존댓말로 세 문장 안팎으로 답한다.
상담자가 자해나 자살에 대한 생각, 당장의 위험을 말하면 혼자 견디지 않도록 권하고, 자살예방 상담전화 109나 정신건강 위기상담전화 1577-0199, 긴급한 경우 119로 바로 연락하도록 안내한다.
```

## 2. 노션 데이터베이스 구조

페이지 이름은 `상담기록`이고, 페이지 안에 빈 표 형식의 데이터베이스를 만든다. 데이터베이스의 행 하나가 세션 하나의 상담 기록이다.

| 속성 | 속성 유형 | 값을 넣는 주체 | 내용 |
|---|---|---|---|
| `이름` | 제목 | 워크플로우 | `상담 2026-09-10 14:30`처럼 상담을 시작한 시각이 들어간 제목 |
| `SessionID` | 텍스트 | 워크플로우 | `채팅 받기`가 만든 `sessionId` |
| `상담일시` | 생성 일시 | 노션 | 행을 만든 시각. 노션이 자동으로 채우므로 워크플로우에서 넣지 않는다 |

제목 속성의 기본 이름은 노션의 언어 설정에 따라 다를 수 있다. 질문과 답은 속성이 아니라 행을 열었을 때 보이는 페이지 본문에 블록으로 쌓는다.

## 3. 시험 대화

| 번호 | 보낼 문장 | 확인할 점 |
|---|---|---|
| C-1 | 부서를 옮기고 나서 밤에 잠이 잘 안 와요. | 공감하는 답이 온다. 노션에 새 행이 하나 생긴다 |
| C-2 | 그것 때문인지 아침에 일어나기도 힘들어요. | "그것"을 앞의 대화와 이어서 답한다. 노션의 같은 행 본문에 질문과 답이 추가된다 |
| C-3 | 제가 처음에 뭐가 힘들다고 했죠? | 앞의 대화를 근거로 답한다 |
| C-4 | (새 세션에서) 제가 처음에 뭐가 힘들다고 했죠? | 앞의 대화를 알지 못한다. 노션에 다른 행이 생긴다 |
| C-5 | (n8n을 다시 시작한 뒤) 제가 처음에 뭐가 힘들다고 했죠? | 앞의 대화를 알지 못한다. 노션의 기록은 그대로 남아 있다 |
