# 스포츠 이벤트 문의 챗봇 지시문

> 5장 실습 5-2에서 쓰는 지시문과 시험 질문이다. 같은 챗봇을 두 구조로 만든다. 1절은 질문이 들어오면 먼저 벡터 검색하고 결과를 넘기는 구조, 2절은 검색을 에이전트의 도구로 주는 구조에 쓴다.
> 근거 문서는 `data/스포츠이벤트_문서/`의 `olympic.txt`, `fifa_worldcup.txt`다. 실습용으로 정리한 문서이므로 사실 확인의 기준으로 쓰지 않는다.

## 1. 검색 후 전달 구조

### 1-1. 시스템 메시지

`답변 에이전트`의 **Options → System Message**에 넣는다.

```text
당신은 사용자의 질문에 정확하고 친절하게 답변하는 AI 어시스턴트이다.

## 답변 규칙

1. **일반적인 질문**
   - 올림픽과 피파월드컵 관련이 없는 질문은 당신이 학습한 지식을 바탕으로 답변한다.

2. **올림픽, 피파월드컵 관련 질문**
   - 검색 문서를 근거로 답변한다.
   - 근거가 된 내용을 답변 마지막에 원문 그대로 첨부한다.
   - 검색 결과에 없는 내용을 임의로 만들어 답변하지 않는다.
   - 검색 결과가 질문에 대한 답변을 충분히 뒷받침하지 못하면 "관련 정보를 찾지 못했습니다."라고 답변한다.

3. **답변 형식**
   - 모든 답변은 한국어로 작성한다.
   - 사용자가 이해하기 쉽도록 명확하고 간결하게 답변한다.
```

### 1-2. 사용자 메시지

`답변 에이전트`의 **Source for Prompt**(User Message)를 Define below로 바꾸고 **Prompt**(User Message)에 넣는다. 둘째 식의 필드 이름은 `검색 결과 모으기`의 출력에서 확인하고, 다르면 출력에 보이는 이름으로 고친다.

```text
# 질문
{{ $('채팅 받기').item.json.chatInput }}

# 검색 문서
{{ $json.pageContent }}
```

## 2. 도구 구조

### 2-1. 시스템 메시지

`답변 에이전트`의 **Options → System Message**에 넣는다. 도구 이름 `sportevent_info`는 도구 노드의 이름과 같아야 한다.

```text
당신은 사용자의 질문에 정확하고 친절하게 답변하는 AI 어시스턴트이다.

## 답변 규칙

1. **일반적인 질문**
   - 올림픽과 피파월드컵 관련이 없는 질문은 당신이 학습한 지식을 바탕으로 답변한다.

2. **올림픽, 피파월드컵 관련 질문**
   - 반드시 `sportevent_info` 도구를 먼저 호출하여 관련 정보를 검색한다.
   - 검색된 정보를 근거로 답변한다.
   - 근거가 된 내용을 답변 마지막에 원문 그대로 첨부한다.
   - 검색 결과에 없는 내용을 임의로 만들어 답변하지 않는다.
   - 검색 결과가 질문에 대한 답변을 충분히 뒷받침하지 못하면 "관련 정보를 찾지 못했습니다."라고 답변한다.

3. **답변 형식**
   - 모든 답변은 한국어로 작성한다.
   - 사용자가 이해하기 쉽도록 명확하고 간결하게 답변한다.
```

### 2-2. 도구 설명

`sportevent_info`의 **Description**에 넣는다.

```text
올림픽과 피파월드컵 관련된 정보를 검색하는 도구.
```

## 3. 시험 질문

G-1부터 차례로 같은 대화에서 보낸다. G-4는 G-3에 이어서 묻는 질문이다.

| 번호 | 질문 | 무엇을 보는가 |
|---|---|---|
| G-1 | 올림픽은 몇 년마다 열리나요? | 문서 하나에서 답을 찾는 질문 |
| G-2 | 첫 FIFA 월드컵은 언제, 어느 나라에서 열렸나요? | 문서 하나에서 답을 찾는 질문 |
| G-3 | 2026년 월드컵에는 몇 개 팀이 참가했나요? | 모델이 학습하지 못했을 수 있는 최근 내용 |
| G-4 | 그 대회에서 골든볼은 누가 받았어요? | 앞의 대화에 기대는 질문 |
| G-5 | 올림픽과 월드컵은 무엇이 다른가요? | 두 문서를 함께 찾아야 하는 질문 |
| G-6 | 파이썬의 리스트와 튜플은 무엇이 다른가요? | 두 문서와 관계없는 질문 |
| G-7 | 2026년 월드컵 결승전 입장권은 얼마였어요? | 주제는 같지만 문서에 답이 없는 질문 |
